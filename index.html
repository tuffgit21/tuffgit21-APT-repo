tuffgit21 APT Repository

Debian/Ubuntu repository hosted on GitHub Pages.

Quick setup

echo "deb [trusted=yes] https://tuffgit21.github.io/tuffgit21-APT-repo stable main" | sudo tee /etc/apt/sources.list.d/tuffgit21.list
sudo apt update
sudo apt install <package>

Note: [trusted=yes] is needed because this repo is currently unsigned. To remove it, sign dists/stable/Release with GPG and distribute the public key.
